# Vibes CRM

A minimalist, high-aesthetic personal CRM designed for marketers and creators. 

All your data stays securely in your browser's local storage. No backends, no databases to manage. Just pure vibes.

## Features
- ✨ Ultra-minimalist dark UI (Linear/Apple aesthetic)
- 💾 Zero-configuration: Runs entirely in browser (LocalStorage)
- 🚀 Instant load times
- 📊 1-Click CSV Export
- ⚡ 1-Click Deploy to Netlify

## Deploy

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=YOUR_GITHUB_REPO_URL)

*(Note: Replace `YOUR_GITHUB_REPO_URL` in this README with your actual GitHub repository URL once pushed).*

## Usage
Simply open `index.html` in any modern browser or host it anywhere (Netlify, Vercel, GitHub Pages).
